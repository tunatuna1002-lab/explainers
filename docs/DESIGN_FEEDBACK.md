# 디자인 피드백 (모든 글에 적용)

새 글을 쓰거나 디자인을 고치기 전에 이 파일을 먼저 읽는다. 아래 "반드시 지킬 규칙"은 모든 글에 적용한다.

## 반드시 지킬 규칙

### R1. 흐름도 화살표는 짧게 (선 16px)
- 파일: `src/components/canvas/Diagram.tsx`
- 값: `RANK_GAP = 32`, `CLEAR = 8` → 보이는 선 길이 = 32 − 8 × 2 = 16px
- 이전 값 `RANK_GAP = 56`(선 40px)은 너무 길다는 피드백을 받았다.

### R2. 목차는 화면 왼쪽 끝 (현재 배치 유지)
- 파일: `src/components/canvas/canvas.css`
- 값: `--cv-toc: 220px`, `--cv-main: 700px`
- 그리드: `minmax(var(--cv-toc), 1fr) minmax(0, var(--cv-main)) minmax(0, 1fr)` → 목차는 왼쪽 끝, 본문은 화면 가운데
- 목차: `position: sticky; top: 28px; padding-top: 60px`
- 1040px 미만 화면에서는 목차가 제목 아래로 내려간다.
- 튜링 글(쿨톤, Q&A 8개, 목차 왼쪽 끝)이 승인된 기준이다.

## 피드백 기록

| 날짜 | 피드백 | 반영 | 규칙 |
|---|---|---|---|
| 2026-11-02 | 흐름도 단계 사이 화살표가 너무 길다 | RANK_GAP 56 → 32 (선 40px → 16px) | R1 |
| 2026-11-02 | 목차는 지금 배포된 튜링 글처럼 왼쪽 끝에 둔다 | 현재 값 유지 | R2 |

## 운영 방법
1. 새 피드백은 "피드백 기록"에 한 줄씩 쌓는다.
2. 같은 요구가 다시 나오거나 모든 글에 해당하면 "반드시 지킬 규칙"으로 올린다.
3. 규칙 값을 바꾸면 이 파일의 값도 함께 고친다.
